# OIBSP: Oasis Infobyte Python internship

Five Python applications built during my 2024 software development internship at Oasis Infobyte. Each was specified, built and demoed on its own.

| App | What it does |
|---|---|
| [Voice Assistant](voice_assistant_project) | Speech recognition that parses spoken intent into system commands |
| [Weather App](Weather%20App) | Fetches current conditions from a REST weather API |
| [Chat Application](Chat%20Application) | Multi-client TCP chat server with a GUI client, login and SQLite message storage |
| [Random Password Generator](Random%20Password%20Generator) | Configurable password generator |
| [BMI Calculator](BMI%20Calculator) | BMI calculator with category feedback |

Each folder has its own README with setup and run instructions.
